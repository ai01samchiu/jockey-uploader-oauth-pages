Privacy policy

Jockey Uploader is a personal tool run by the owner of this repository. It is not a company and has no public accounts.

It uses the owner's own Google account OAuth tokens only to upload videos to the owner's own YouTube channel through the YouTube Data API. YouTube upload does not use a service account. If configured by the owner, a separate Google service account reads and updates the owner's own Google Drive files and a private Google Sheet. That service account is not used to upload to YouTube.

Tokens are stored only where the owner configures them, such as GitHub Actions secrets or local token files. The tool does not sell data.

Contact: GitHub Issues.
